# Digital Gav

A lightweight, responsive village information platform built with plain HTML, CSS and JavaScript.

## Files

- `index.html` – homepage
- `style.css` – layout and responsive styling
- `script.js` – mobile menu, village search and current year
- `assets/images/` – add optimized village photographs here

## Run locally

Open `index.html` in a web browser. No build command or package installation is required.

## Cloudflare Pages settings

- Framework preset: `None`
- Build command: leave empty
- Build output directory: `/` (root)
- Root directory: leave empty
- Production branch: `main`

## Important

The village cards currently show sample/coming-soon content. Verify village names, facts, photographs and contact details with the relevant community before publishing. Do not present this site as an official Gram Panchayat website unless you have authorization.

## Add village pages later

We will add individual static pages under `villages/<village-slug>/` and link them from this homepage as the project grows.
